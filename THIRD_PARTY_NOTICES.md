## Noto Sans CJK SC

`main/ui_font.inc` contains a generated 2-bit bitmap subset of Noto Sans CJK SC Regular. Preview images in `docs/` use that subset and the same upstream typeface for captions. The subset is generated by `tools/generate_font.py`; it is distributed under the SIL Open Font License 1.1, not the project's MIT license.

## Protocol research

The IINE frame format was studied using [x20ctl's KeyLinker protocol investigation](https://github.com/AmjadAAYD/x20ctl/blob/553ad76f89d19706a1bd0e45d8aab6f2c14ed231/docs/01-protocol.md). That upstream project is licensed under GPL-3.0. This repository does not bundle or import its Python implementation; the bounded C codec was independently implemented from protocol behavior. The L1241 input layout was established using physical button and stick tests.
